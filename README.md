# KalibVPN bot

Telegram-бот для продажи доступа к VPN на панели **3x-ui v3** (VLESS + Reality). Клиенты сами получают ключ, оплачивают и продлевают подписку, а админ управляет всем прямо из Telegram.

## Возможности

**Для клиентов**
- 🔑 ключ `vless://` (и ссылка-подписка, если включена в 3x-ui); после продления ключ не меняется;
- 💳 оплата Telegram Stars и картой через ЮKassa;
- 🎁 пробный период (один раз на пользователя);
- 👥 реферальная программа: пригласившему +N дней за первую оплату друга, другу бонус к первой покупке;
- ⏰ напоминание за 3 дня до окончания доступа.

**Для админа** (`/admin` или кнопка «🛠 Админка»)
- 📊 статистика: пользователи, активные ключи, выручка за сегодня / 30 дней / всё время;
- 👥 список пользователей и поиск по ID или @username; в карточке — начислить дни, отключить/включить, отправить ключ;
- 📢 рассылка любого сообщения всем пользователям с предпросмотром;
- 💰 изменение цен тарифов без правки кода;
- 🎭 смена маскировки Reality (домен `target`/`serverNames`) с проверкой домена и рассылкой новых ключей;
- уведомления о каждой оплате и о проблемах с выдачей доступа.

## Структура

| Файл | Что внутри |
|---|---|
| `bot.py` | клиентская часть, оплата, напоминания, точка входа |
| `admin.py` | админ-панель |
| `services.py` | общая логика: выдача доступа, ключи, рефералка, маскировка, рассылки |
| `xui.py` | клиент API 3x-ui v3 |
| `db.py` | SQLite: пользователи, оплаты, настройки |
| `config.py` | настройки из `.env`, тарифы по умолчанию, тексты профиля бота |

## Настройка

1. Создайте бота в @BotFather и получите токен.
2. В 3x-ui: **Настройки → Учетная запись → Токен API → Новый токен** (права admin).
3. Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен бота |
| `ADMIN_IDS` | Telegram ID админов через запятую |
| `PANEL_URL` | адрес панели с секретным путём, без `/` в конце |
| `PANEL_TOKEN` | API-токен 3x-ui |
| `PANEL_VERIFY_SSL` | `false` для самоподписанного сертификата или входа по IP |
| `INBOUND_ID` | ID инбаунда, куда добавляются клиенты |
| `SERVER_HOST` | публичный IP/домен сервера |
| `SUB_URL` | *(необяз.)* адрес подписки 3x-ui без subId |
| `YOOKASSA_TOKEN` | *(необяз.)* платёжный токен из @BotFather → Payments |
| `TRIAL_DAYS` | пробный период, дней (0 — выключен) |
| `REF_BONUS_DAYS` / `REF_FRIEND_DAYS` | бонусы рефералки |

## Запуск на сервере (Ubuntu/Debian)

```bash
apt install -y python3-venv git
git clone <repo> /opt/vpn-bot && cd /opt/vpn-bot
python3 -m venv venv && venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
cp vpn-bot.service /etc/systemd/system/
systemctl daemon-reload && systemctl enable --now vpn-bot
journalctl -u vpn-bot -f   # логи
```

Обновление: `cd /opt/vpn-bot && git pull && systemctl restart vpn-bot`.

## Заметки

- Клиенты бота в панели называются `tg<telegram_id>`, остальных клиентов бот не трогает.
- После смены маскировки старые ключи этого инбаунда перестают работать — бот предложит разослать новые. Клиентов, созданных в панели вручную, нужно обновить самостоятельно.
- Аватарка бота — `assets/avatar.png` (ставится через @BotFather → `/setuserpic`). Описание и команды бот выставляет себе сам при запуске.
